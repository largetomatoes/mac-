# 问间

问间是一个以“我们该如何处理我们和世界的关系？”为核心问题的本地笔记系统。它把问题、回答、交叉思考、阅读摘录和文稿放在同一张关系图中，同时保留思考的来源、时间与修改过程。

## 下载

在仓库右侧的 **Releases** 中下载最新的 `Wenjian-*-macOS.zip`，解压后把“问间”拖入“应用程序”文件夹。应用采用本地存储，不需要登录，也不会把笔记上传到服务器。

首次打开时，如果 macOS 提示无法验证开发者，请在 Finder 中按住 Control 点击“问间”，选择“打开”。当前发布包是 ad-hoc 签名版本，尚未经过 Apple 公证。

## 主要功能

- 问题树、回答与自动编号
- 多个板块之间的交叉思考
- 卡片集与后续思考
- PDF、扫描版 PDF 和 EPUB 阅读
- PDF 本地 OCR、原文高亮和阅读笔记
- EPUB 自动记录章节，PDF 手动填写章节
- 文稿写作与句子级问题引用
- 修改记录、全局搜索和只读分享
- 本地 JSON 数据、自动备份及可选坚果云目录同步

## 数据与隐私

正式数据不属于代码仓库，也不会被 Git 跟踪。默认数据位于 macOS 的“应用支持”目录；配置坚果云后，问间只使用独立的“问间同步”目录，不会混入 Obsidian 笔记目录。书籍文件和 OCR 缓存同样只保存在本机或用户选择的同步目录。

## 开发

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev
npm run build
npm run lint
node scripts/test-cross-blocks.mjs
```

网页界面位于 `app/` 和 `components/`。macOS 本地服务与应用壳源码位于 `work/mac-app/`。仓库只包含可复现构建所需的壳源码、图标与空白种子数据，不包含 Electron 依赖、构建产物、用户笔记或电子书。
